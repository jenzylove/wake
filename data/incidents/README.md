# Real incident captures

This directory is reserved for evidence packets generated by `npm run data:capture`. A capture contains a real chain transaction receipt and a paginated, deduplicated Bitget historical mark-price window; it is not a mock fixture. The capture command rejects mismatched receipts and never substitutes missing market data.

Run the capture script with a specific incident transaction and market window:

```sh
npm run data:capture -- --incident INC-REAL-001 --chain-id 1 --tx 0x... --symbol BTCUSDT --start 1700000000000 --end 1700003600000
```

Set `CHAIN_RPC_URL` or `ETHERSCAN_API_KEY` for the chain receipt. Bitget market history is a public endpoint and does not require an API key. Generated captures should be reviewed before being used as a judge-facing scenario.

The repository includes three verified captures: Moonwell/Base (`inc-real-moonwell-20260827.json`), AFX/Arbitrum bridge outflow (`inc-real-afx-20260722.json`), and AFX/Arbitrum recovery response (`inc-real-afx-resolution-20260723.json`). Run `npm run data:verify` to verify every packet before presenting it.
